## 📖 نظرة عامة (Overview)

تعتبر **بوابة تقانة المعلومات - جامعة النيل الأبيض** منصة ويب تفاعلية تهدف إلى تسهيل الوصول إلى المصادر الأكاديمية، المحاضرات، والجداول الدراسية، فضلاً عن توفير بيئة رقمية متكاملة ومترابطة تعزز تجربة التعلم وتدعم التواصل الفعّال داخل مجتمع الكلية.

---

## ✨ المميزات الرئيسية (Features)

* **واجهة مستخدم عصرية:** تصميم متجاوب يعمل بكفاءة عالية على الهواتف الذكية والأجهزة اللوحية والحواسيب.
* **تنظيم أكاديمي متكامل:** تصفح سهل للمقررات، المستندات، والرواتب الأكاديمية المرتبطة بالقسم.
* **تكامل قواعد البيانات:** ربط مرن ومنظم للمحتوى لضمان سرعة الاستجابة واسترجاع البيانات.
* **دعم اللغتين:** واجهة داعمة للغة العربية باتجاه صحيح (RTL) مع إمكانية التبديل المرن.

---

## 🛠️ التقنيات المستخدمة (Tech Stack)

تم بناء المشروع باستخدام مجموعة من أحدث التقنيات المعيارية لضمان خفة الوزن وسرعة التحميل:

* **Frontend:** HTML5, CSS3, JavaScript (ES6+)
* **Styling & Effects:** Modern CSS (Flexbox, Grid, CSS Variables, Glassmorphism UI)
* **Version Control:** Git & GitHub Pages

---

## 🎨 التصميم البصري وتجربة المستخدم (Visual Design)

يتميز المشروع بتجربة بصرية فريدة ومصممة بعناية داخل ملفات التطبيق (وليس في ملفات التوثيق)، وتتضمن:
* **التصميم الزجاجي (Glassmorphism):** تأثيرات شفافة وأنيقة لعناصر الواجهة مع ضبابية خلفية خفيفة.
* **التدرجات اللونية (Gradients):** دمج متناسق للألوان المعبرة عن هوية تقانة المعلومات والجامعة.
* **الرسوم المتحركة التفاعلية:** انتقالات سلسة (Transitions & Animations) عند التنقل بين الأقسام لعكس طابع حيوى ومهني.
