## 📖 نبذة عن المشروع (About)
تم تطوير **بوابة تقانة المعلومات** الخاصة بطلاب جامعة النيل الأبيض (كستي) لتكون بيئة رقمية أكاديمية متقدمة تسهل على الطلاب عمليات التسجيل، التحقق من الأرقام الجامعية عبر قواعد بيانات سحابية مشفرة، وتوفير لوحة تحكم تفاعلية ذكية تدعم اللغتين العربية والإنجليزية وتغيير المظهر (الثيمات).

---

## ✨ المميزات والخصائص الرئيسية (Key Features)
* **🔐 نظام مصادقة أکاديمي مزدوج:** دعم تسجيل الدخول الآمن وإنشاء حسابات طلابية جديدة مع ربطها بقاعدة البيانات.
* **🔥 التحقق السحابي عبر Firebase Firestore:** التحقق الفوري من صحة "الرقم الجامعي" للطالب من قاعدة بيانات الجامعة الرسمية قبل السماح بإنشاء الحساب.
* **🌐 دعم متعدد اللغات (AR / EN):** إمكانية تصفح المنصة بالكامل باللغة العربية أو الإنجليزية مع التبديل التلقائي لاتجاه الواجهات (RTL / LTR).
* **🎨 واجهات بروفيشنال وتصميم متجاوب (Responsive Design):** واجهات عصرية مصممة بأعلى معايير الجودة لتتلائم مع الهواتف الذكية والأجهزة اللوحية والحواسيب.
* **🔄 استعادة كلمة المرور المتقدمة:** نظام تحقق ذكي عبر رموز التحقق (OTP) وواجهات حماية (Captcha).
* **⚡ أداء عالي وسرعة استجابة:** مبني بأحدث تقنيات الـ Frontend السريعة والخفيفة دون تعقيدات مكتبات الإطار الثقيلة.

## 🛠️ التقنيات المستخدمة (Tech Stack)
تم بناء وتطوير هذا المشروع باستخدام أحدث تقنيات الويب الحديثة:
* **HTML5 / CSS3:** لهيكلة وتصميم الواجهات العصرية بمرونة عالية.
* **JavaScript (ES6+):** للتحكم بالمنطق البرمجي، التفاعل، وإدارة الحالة المحلية (LocalStorage).
* **Firebase (v12.19.0):** 
  * *Cloud Firestore* (قاعدة البيانات السحابية للتحقق من الطلاب).
* **Lottie Animations:** لرسومات متحركة جذابة وسلسلة تعزز تجربة المستخدم (UI/UX).
